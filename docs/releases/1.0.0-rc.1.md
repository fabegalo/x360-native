# v1.0.0-rc.1 — Windows x64 Release Candidate

Local candidate for the first stable version. The maintainer accepted the four
manual workflows on the Preview 25 installation: original dashboard/game/Guide
return, progress save and reload after restart, graphical import/preparation,
and clean Windows installation/update with data preservation.

Recovered receipts and logs identify Retail 17559 and Forza Horizon 0.0.0.10
with Xenos D3D12. See [STABLE-03](../stability/homologation-stable-03-2026-10-28.md)
for hashes, documented observations and gaps in historical machine/update data.
These manual observations belong to Preview 25, not a new visual run of this RC.

The candidate integrates reviewed MAINT-01 tooling, preserves development
launcher staging and copies original supervisor/extractor targets into the
distribution. Maintenance protects originals, prepared products and user data.
The pinned ReXGlue revision and all 201 patches are unchanged.

The final HEAD requires a fresh complete stability gate and a fresh verified
ZIP; their local receipts record outcomes and remaining blockers. No claim of
universal game support, campaign completion or performance is made. Native and
Vulkan remain experimental. This task does not publish the final v1.0.0.

# v0.1.0-preview.22 — Faster preparation, responsive launcher and AOT progress

Experimental Windows x64 desktop preview, built from this tagged source revision.
The package does not contain original Xbox 360 games, dashboards, firmware,
XEX files, private data or compiled game products. Xenos/D3D12 remains the
default renderer; Native D3D12 development is suspended. Vulkan is unavailable.

## Changes since preview.21

- Reorganized source, build tools and content layouts while preserving
  original inputs and strict dashboard-version isolation.
- Integrated the Retail 17559 shared XAM/avatar service, implemented the
  identified original 17559 sign-in callback, and corrected Motocross Madness
  terrain/rider paths and its AOT callback.
- Expanded generic AOT function discovery, guarded byte-dispatch handling and
  preparation of dependent XEX modules. Charlie Murder's 31 native DLLs,
  receipts and original My Games registration/routing passed focused checks.
  One isolated session reached HostLoader, RuntimeHost and NetCF bootstrap,
  then returned to the dashboard; XNA and gameplay were not certified.
- Improved SDL window focus, supervisor lifecycle notifications, desktop
  responsiveness and catalog enumeration. A same-collection catalog
  measurement fell from about 84–85 seconds to 5.98 seconds.
- Added content-verified incremental native/AOT builds, authenticated
  checkpoints and source/header/toolchain/response-file invalidation.
  Four recorded no-op preparations improved by 31.7–33.0%. One measured
  full Retail 17559 build improved from 703.12 to 552.65 seconds (21.4%).
  Some small-change incremental builds remain expensive.
- Optimized protected launch validation without dropping SHA-256 checks.
  On the tested warm-cache collection, verification before process creation
  improved from 31.27 to 19.35 seconds (17559), 9.27 to 7.74 (Charlie),
  10.91 to 7.98 (Motocross) and 8.12 to 6.88 (Castle). The 17559 still
  reads approximately 22 GB for full integrity verification.
- Bounded local smokes recorded GPU swaps for 17559, Motocross and Castle.
  Charlie returned after NetCF bootstrap without swaps. These results are
  not time-to-visible-frame, gameplay, FPS or performance-of-games claims.

ReXGlue v0.10.0 remains pinned to
f5337cdc947ff6d4c4196737e2c807a48f2a1fc2, LLVM to 22.1.8, and
91 active reproducible SDK patches (through 0092; patch 0073 withdrawn).

## Download, first use and updating

Download the Windows x64 ZIP and its SHA-256 checksum from this Release,
verify the checksum, extract the whole ZIP into a new folder and open the
desktop application. GitHub's automatic source archives are not runnable
desktop distributions.

Preserve the existing **data/** environment, imported titles, catalog,
profiles, saves and originals. Use the managed source update in Settings
to point the updated desktop app at the existing environment. Do not delete
or relocate private .local content to update. Changed build inputs can
legitimately require regenerating prepared title products.

The ZIP does not ship the full compiler/toolchain or original Xbox content.
The application obtains supported pinned tools with consent; additional
Microsoft C++ build dependencies may require official installation.

## Verification and compatibility limits

The GitHub-hosted Windows release workflow builds and checks the desktop
package, focused distribution tests, license/content boundaries, original
file exclusions, complete payload manifests, and ZIP/SHA-256 integrity before
publication. A successful hosted package does **not** certify the complete
first-use experience on a clean Windows installation.

- No Xbox Live or full Xbox firmware/XAM/kernel emulation is provided.
- Retail 17559 has historical original intro, navigation, profile and
  launch/return observations; its system services/settings remain partial.
  Other dashboard generations need their own original inputs and validation.
- Charlie Murder reached HostLoader / RuntimeHost / NetCF in an isolated
  session, but NetCF mapper/PTE compatibility remains unresolved. XNA,
  rendering, input, Guide, sustained gameplay and commercial saves have
  no functional acceptance.
- Motocross Madness has corrected AOT and sign-in callbacks and bounded
  runtime evidence, but its complete My Games/profile/Guide route,
  graphical fidelity, races and save/load remain unverified.
- Castle Crashers and Forza Horizon have limited prior gameplay/return
  observations; campaign completion and commercial saves are not approved.
  Castle uses a proven production analysis hint for an entry without metadata.
- First-visible-frame timing and actual game runtime performance have not
  been measured by the preparation/preflight benchmarks above.
- Native D3D12 is experimental and suspended. Vulkan, Linux, macOS and ARM64
  are not distribution targets. First use on a clean Windows host is
  not fully validated.

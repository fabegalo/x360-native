# x360-native v1.28.29 — Stable Release

This stable release follows v1.28.28 and fixes one launcher status problem. Everything else is unchanged.

## Fixed

- **"Needs preparing again" after every preparation:** in an installation whose folder is long enough to need the short junction under `%LOCALAPPDATA%\x360n\r`, finishing a preparation marked the dashboard and every other prepared title as needing preparation again. Running the full check in Diagnostics showed them as ready again. Nothing had changed on disk. The preparation records the title's manifest through that junction, and the launcher's quick status check compared that name with the installation's own spelling as written. The quick check now resolves both names, as the full check already did. A new test, which uses a real junction, fails without the fix.

## Updating

The launcher checks GitHub Releases at startup and offers newer stable versions after asking you. It verifies the downloaded archive before installing it and keeps your data, imported games, saves and profiles. This release changes only the launcher's status check, not the runtime. Whether your titles need preparing again after the update is decided by the full check, as before.

## Verification and limitations

The fix was checked with the preparation tests on Windows x64 (17 test cases, including the new junction case). It was not exercised in an installed release package before publication. The open limitations of [v1.28.28](1.28.28.md) still apply, among them the crash of the 17559 dashboard right after creating a profile. Windows x64 is still the only platform with end-to-end evidence.

# x360-native v1.28.30 — Stable Release

This stable release follows v1.28.29 and fixes the preparation of Motocross Madness. Everything else is unchanged.

## Fixed

- **Motocross Madness could not be prepared:** since v1.28.x moved preparation into the native pipeline, preparing Motocross Madness stopped with `Missing/unreadable preparation input: …\.local\inputs\default.xex`. The pipeline looked for the title's registered original files in its code generation folder (`.local/inputs`, which must also hold the dashboard's `xam.xex`) instead of the game's content folder. It now uses the content folder (`[x360n] game_data_root`) when a title has one, as the catalog and the importer already did. Other titles use the same folder as before. A new test fails without the fix.

## Updating

The launcher checks GitHub Releases at startup and offers newer stable versions after asking you. It verifies the downloaded archive before installing it and keeps your data, imported games, saves and profiles. The changed file is part of the shared SDK build's identity, so after this update the dashboard and your games need preparation again, and the first preparation compiles the shared SDK build again.

## Verification and limitations

The fix was checked with the preparation tests on Windows x64 (18 test cases, including the new one), and the registered `default.xex` of Motocross Madness 0.0.0.3 was found with its registered SHA-256 in the content folder. A complete preparation and launch of Motocross Madness with this release was not run before publication. The open limitations of [v1.28.28](1.28.28.md) still apply. Windows x64 is still the only platform with end-to-end evidence.

# v0.59.0-preview.24 — Original Profiles, Storage and Vulkan Experiments

Experimental **Windows x64 technical preview**, prepared from the current `main` revision. This is a development preview, not a stable or fully compatible Xbox 360 environment. The ZIP contains the x360-native desktop application, supervisor, extractor and verified workspace sources; **games, dashboard binaries, XEX files, firmware, licensed Xbox assets, profiles and saves are not bundled**.

## Changes since preview.23

- **Retail 17559 profiles and Guide:** Expanded the original Sign-in, CreateProfile, GamerProfile and Guide paths. Added navigation to games/achievements, local profile rename/edit operations and settings, recoverable profile removal and safer system-app transitions. The maintainer confirmed original profile creation through the Guide and that Forza Horizon's original achievement list opens. Remaining image/thumbnail and navigation contracts are not yet fully implemented.
- **Original Storage:** Added persistent virtual HDD, configurable Memory Unit/USB volumes, device capacity/quota reporting, the original device selector and content metadata for multiple owners. Settings → System → Storage was observed with original device categories. Implemented local transactional copy/move contracts with progress, cancellation and space checks, plus profile content packages per storage device. Visual acceptance of transfers, commercial save/load and complete storage management remains pending.
- **Shared session storage:** Titles in a dashboard session use the dashboard's common virtual HDD for XContent. Per-title caches remain separate. Profiles are stored as content packages (`<XUID>/FFFE07D1/00010000/<XUID>`), and account selection is stored separately.
- **Xenos Vulkan (experimental):** Enabled the ReXGlue Vulkan build on Windows, implemented explicit graphics API selection in the launcher/supervisor with no silent fallback and added Vulkan D1OVL composition. Offscreen Vulkan scanout/overlay tests and comparisons with D3D12 passed. Retail 17559, Guide and real gameplay have **not** been certified with Vulkan.
- **Native D3D12:** Improved GPU submission resource lifetime with in-flight arenas. A controlled synthetic 4,096-draw test showed approximately 6.2% lower median process time, **not** a measured gameplay FPS improvement. Native/Vulkan remains unavailable; Native/D3D12 gameplay performance and fidelity are still experimental.
- **Fullscreen:** Alt+Enter and F11 now toggle fullscreen for a persistent session frame and standalone titles while preserving the prior windowed placement.
- **Maintenance:** Kept ReXGlue v0.10.0 pinned to `f5337cdc947ff6d4c4196737e2c807a48f2a1fc2`; SDK changes are tracked in 139 active reproducible patches. Renumbered the Vulkan overlay patch to 0140 and moved withdrawn patch 0073 out of the active directory.

## Important data compatibility warning

**The new profile storage layout does not automatically migrate legacy `profiles/local-v2.dat` identities.** Existing files are preserved, but older local profiles will not be enumerated by the new backend. Likewise, saves previously written under individual title user-data roots are not automatically migrated to the new dashboard-wide HDD. **Do not delete or overwrite an existing environment to test this preview.** Preserve your previous installation and its complete user data, use a separate test environment, and keep backups before changing storage settings.

Do not interpret profiles or saves appearing absent in the new UI as authorization to erase the old data.

## Download and installation

Download `x360-native-0.59.0-preview.24-windows-x64.zip` and its corresponding `.zip.sha256` file from this GitHub Release **only after the tag-triggered build and verification finish successfully**. Verify the SHA-256, extract the entire ZIP to a new folder and run `x360-native.exe`. GitHub's automatic source archives are not standalone Windows applications.

The release pipeline creates the desktop distribution, not precompiled AOT versions of commercial games or original Xbox 360 dashboards. Separate pinned developer tools and Microsoft C++ components may be necessary for preparation with user consent. Preview-channel updates require explicit opt-in.

## Verification and limitations

The GitHub Actions release workflow verifies the exact tag revision, source/toolchain provenance, pinned patches, release configuration, package contents and licenses, ZIP integrity and SHA-256 before publishing. Passing the hosted package gates **does not** constitute functional acceptance of original UIs, graphics backends, gameplay or compatibility.

- Retail 17559 profile creation, Guide and achievement navigation have progressed, but full multi-user support (beyond one active local user in slot 0), gamer pictures and complete original UI coverage remain unfinished. Reported past guest-memory crashes are not automatically certified as fixed.
- Storage format/metadata remain an offline implementation, not an original signed or encrypted Xbox container. Device operations and profile transfers require additional visual validation. Virtual-device formatting and complete commercial save/load cycles are not certified.
- The legacy profile/save storage change has **no automatic migration**. Test with isolated data. Do not overwrite personal profiles, saves or previous installations.
- Xenos/D3D12 remains the Windows default. Xenos/Vulkan is experimental and only validated by focused probes; its packaging/runtime completeness and dashboard/gameplay still require acceptance. Native/D3D12 is experimental and not performance-certified. **Native/Vulkan is not implemented.**
- Retail 1888 and other dashboards remain separate compatibility targets, not certified by Retail 17559 tests. Xbox Live, cloud storage, complete firmware emulation, Linux, macOS and ARM64 are not supplied by this Windows ZIP.

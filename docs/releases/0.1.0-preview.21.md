# v0.1.0-preview.21 — Desktop refresh, original Guide and preparation fixes

Windows x64 pre-release, incorporating the changes on main since preview.20.
Xenos remains the default renderer. Original Xbox content is not included.

## Changes since preview.20

- Redesigned the native Windows desktop manager with a shared dark theme,
  DPI-aware controls, searchable/filterable Library, clearer preparation stages,
  retry actions and diagnostics. Renderer preferences persist across sessions.
- Fixed import staging on long Windows paths and persistence of Unicode file
  errors. Retry reuses verified copies while preserving conflicting existing data.
- Shortened generic AOT build/codegen paths, preserved project ownership when
  the SDK refreshes generated integration, and corrected analysis boundaries
  around gaps in PowerPC function metadata.
- Added the exact-content Forza Horizon 0.0.0.10 analysis profile, original
  facade modules and native fiber lifecycle support. Recorded local validation
  reached driving and the original My Games / Xbox Home return flow; this does
  not certify the campaign, all content or commercial save/load.
- Preserved the selected dashboard profile across title transitions and exposed
  executable metadata to the original library. Captured helper processes no
  longer open auxiliary consoles.
- Composed the original 17559 Guide through XAM system command buffers at
  VdSwap, using shared runtime infrastructure instead of per-game drawing hooks.
  The title remains visible behind the dimmed Guide. Closing Profile returns to
  the Guide, and Xbox Home preserves caller context through runtime teardown.
- Isolated system UI input from the title, including the Guide button and keys
  still held when the Guide closes. Local observations cover the dashboard,
  Castle Crashers and Forza Horizon on Xenos/D3D12.
- Fixed empty Xenos resolves and draws with provably inactive vertex fetches.
  These correctness fixes do not establish a general FPS improvement.
- Added optional, normally disabled runtime measurements, bounded captures and
  provenance checks. A register metadata optimization was withdrawn after worse
  1% lows; the negative result remains documented. No global performance gain
  is claimed.
- Integrated experimental Native D3D12 work, including guest draws, textures,
  pipeline caching and reduced waits for inactive views. Native remains
  suspended and experimental, without performance acceptance; Xenos is the
  supported default path for the observations above.
- Added the official hosted Windows release workflow: pinned dependencies,
  focused distribution tests, license/content gates, complete ZIP inventories,
  source/toolchain provenance and verified publication of ZIP plus SHA-256.

ReXGlue remains pinned to `f5337cdc947ff6d4c4196737e2c807a48f2a1fc2`
and LLVM to 22.1.8. There are 78 active reproducible SDK patches, numbered through
0079 with 0073 withdrawn. C7/C8 contracts and dashboard-version isolation remain
in place: every version requires its own identified original modules/resources.

## Updating

Extract the complete ZIP into a new folder. Select the existing environment in
Settings and apply the managed source update. Keep the old data folder and its
imports, catalog, preferences, profiles and saves. Do not delete or move `.local`
to update sources. Changed preparation inputs invalidate old receipts and may
require preparing the dashboard and games again.

## Evidence and remaining limits

The linked reports describe earlier focused tests and bounded local sessions;
they are not a new certification of every game or of this packaged build.
The release workflow separately builds and validates the desktop distribution.

The first hosted attempt withheld the ZIP because a session-host test compared
the Windows TEMP short-name alias with its canonical path. The test now resolves
the existing fixture root before checking the exact expected host path; runtime
behavior and rejection checks are unchanged.
The next attempt passed the distribution tests and exposed an outdated OS DLL
allowlist. Packaging now recognizes the Windows GDI+ and UxTheme dependencies
already linked by the desktop interface; no DLLs are bundled or harvested.

The Guide still lacks profile data such as gamerpic and achievement counts;
Guide-to-Profile can briefly show an undimmed title frame. Other languages,
Vulkan and other games were not validated for this composition path. The full
supervisor round trip was not repeated in the latest Guide revision.

Native Vulkan is unavailable and Native D3D12 has unresolved rendering limits.
Charlie Murder remains blocked by a missing AOT function. Clean-Windows first
use, broad gameplay compatibility, commercial save/load, Xbox Live, Linux,
macOS and ARM64 remain unverified or unsupported as documented in
[STATUS](https://github.com/fabegalo/x360-native/blob/v0.1.0-preview.21/STATUS.md).
Importing or compiling a title does not mean it is playable.

# x360-native v1.28.13 — Automatic Update Migration Hotfix

This stable release fixes the launcher updater for the archive-only GitHub Releases introduced in v1.28.8 and v1.28.11, while preserving the compatibility needed to update already-installed launchers automatically.

## Fixed

- The updater now recognizes a platform-specific Release archive when GitHub provides a valid `sha256:<64 lowercase hex digits>` asset digest, even without a separately uploaded `.sha256` file.
- Before extracting or replacing any application file, the downloaded archive is hashed and checked against the SHA-256 from the GitHub Releases API. Missing, malformed, or mismatched checksums fail closed.
- Older Releases with a separate `.sha256` asset remain supported as a fallback. A Release with no usable checksum is not offered or installed.
- Added unit tests for archive-only release discovery, checksum verification, corrupted archives, missing/malformed hashes, legacy fallback, and platform selection.
- **One-time compatibility bridge:** this v1.28.13 Release publishes six verified installation archives **plus six SHA-256 sidecars**. The already-installed v1.28.11 updater requires the separate checksum file to discover an update. Releases after the bridge return to six public archives.

The six `.sha256` files in this transition Release support automatic upgrades from older installed launchers. They are not additional installers. GitHub's generated source archives are not application packages.

## Updating

The installed launcher checks for stable releases on startup and offers the update for user confirmation; it does not update without approval. Preserve existing `data/`, profiles, library, saves and dashboard/game inputs. The transaction mechanism checks package integrity, stages files and has rollback/recovery support.

Users with v1.28.11 or earlier archive-only detection behavior should now be able to discover this transition Release because its six checksum sidecars are present. As with any self-updater, first-use end-to-end testing on Windows/Linux/macOS is still recommended.

## Scope and limitations

This update fixes release discovery and integrity verification, not game or dashboard compatibility, GPU performance or SDK build correctness. CI checks alone do not prove first-use updater success on all supported operating systems.

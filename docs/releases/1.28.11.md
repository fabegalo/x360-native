# x360-native v1.28.11 — Stable Hotfix

This stable maintenance release follows v1.28.8 and focuses on restoring reliable game and dashboard preparation after the first stable tag, particularly on Windows installations in deeper folders. It also simplifies public download assets. It does not certify additional games, dashboards or graphics modes.

## Fixed

- **ReXGlue SDK configuration after stable tags (patch 0251):** the SDK previously obtained its version from the x360-native repository when configured as a subdirectory. The project tag `v1.28.8` could therefore make a new preparation fail at `sdk-configure` with `floor version (0.10) is behind tag version (1.28)`. The SDK now reads its **own** repository and uses its pinned version. A regression test covers both tagged and untagged SDK checkouts.
- **Windows paths longer than MAX_PATH:** game preparation could fail before CMake configuration when SDK inputs were located in paths longer than 260 characters, especially inside a user's installation folder with Windows long-path support disabled. Canonicalization and SHA-256 file reads now handle extended-length Windows paths; regression tests exercise paths longer than 300 characters.
- **Cleaner Release downloads:** the publisher still generates and verifies all six SHA-256 checksum sidecars internally, but attaches **only the six installation archives** to the public Release. GitHub also exposes an SHA-256 digest for each asset.

## Installation and upgrades

Extract the package to a new directory and start the launcher (on Windows, `x360-native.exe`). **Back up and preserve** your `data/` folder, local library, dashboard/game inputs, profiles, virtual storage and saves before updating. Do not overwrite an active installation. Previously prepared AOT binaries and SDK receipts may need rebuilding using the updated sources and patches.

The packaged desktop app does not include original Xbox 360 games, system files, licenses, or keys. The launcher prepares only content supplied by the user.

## Compatibility and testing limitations

- Windows x64 and **Xenos D3D12** have the strongest demonstrated end-to-end dashboard and initial game flows; building a distribution for another platform does **not** certify gameplay there.
- Dashboard 17559 remains the main tested target. Older versions, Xenos Vulkan, Native D3D12/Vulkan and generic AOT titles have remaining compatibility and/or performance gaps.
- The SDK version and Windows long-path fixes have targeted regression tests. Full preparation from an extracted v1.28.11 public distribution, with all user environments and titles, has not been established by those tests alone.
- Skate 3, Forza and other games are not certified fully playable; no new real-world FPS improvement is claimed by this hotfix.

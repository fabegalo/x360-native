# v0.1.0-preview.20 — Universal Library and automatic AOT (local candidate)

Windows x64 candidate. No push, tag publication or GitHub Release is authorized
by this preparation. Remote tags were checked: preview.19 was the latest tag and
preview.20 was available.

## Changes

- Import valid Xbox 360 ISO/GDFX images, extensionless CON/LIVE/PIRS packages
  (including XBLA), and extracted game folders into a persistent desktop Library.
- List imported games independently of execution support. The UI distinguishes
  Imported, Not supported, Preparing, Ready and Error. Multiple versions coexist.
- Identify the XEX Title ID, version, media ID, base version, disc fields, region
  and original PE name when present. Read package title/display names and
  publisher metadata when available. Missing metadata stays unknown; a filename
  or Title ID is not presented as a verified marketing name.
- Deduplicate by a deterministic SHA-256 inventory of paths and file hashes.
  Persist incomplete operations before copying, publish verified files atomically,
  resume from verified copies and retain unrelated or conflicting existing data.
- Discover AOT recipes from exact executable and asset hashes. No fixed Castle
  Crashers list is required. New matching recipes can prepare previously imported
  content without deleting the original catalog copy.
- Generate a local AOT project for imported games without any manual recipe.
  Use the pinned SDK's project integration template, LLVM, shared runtime/GPU
  infrastructure and original launch/return handoff. No user source editing is
  required. Existing profiles supply optional exact-content compatibility fixes.
- Reuse native products only when the preparation receipt verifies the content,
  configuration, compiler, SDK, patches, codegen producer and artifacts. Persist
  failures with their actual build stage and log; retry repairs generated projects.
- Register only verified AOT builds in original My Games. Interrupted or stale
  builds lose their managed enumeration header; their game files and saves stay
  intact. The supervisor still validates the selected launch path and receipt.

**Import support and automatic preparation attempts are not execution
compatibility.** Charlie Murder and Forza Horizon are catalogued successfully;
neither is declared playable. Castle Crashers 0.0.1.3 retains its optional
compatibility profile. Launching stays in the original Xbox 360 dashboard.

## Updating

Extract the whole ZIP into a new folder. Select the previous environment in
Settings and apply the managed source update. Keep the old data folder. Existing
imports, settings, profiles and saves retain their locations. Legacy imports
remain visible without a destructive migration. Catalog records live in
`.local/catalog`; imported unsupported content lives in `.local/inputs/library`.
Existing AOT receipts are reused only when their inputs still match; changed
preparation sources can require preparing again.

C7, C8, the pinned SDK and its 67 reproducible patches are preserved. Dashboard
versions continue to use their own original modules/resources and hashes.

## Validation and limits

Real local inputs: Castle Crashers LIVE (584108B7, 0.0.1.3), Charlie Murder LIVE
(58410B83, 0.0.0.2), and Forza Horizon ISO (4D5309C9, 0.0.0.10). The ISO extracted
2,432 files / 7,320,461,527 bytes with zero extraction errors. Folder imports,
multiple versions, duplicates, malformed files, interruption/retry, newly
available recipes and managed My Games registration have focused tests.

Charlie Murder, without a manual title project, completed automatic desktop
project generation, ReXGlue codegen, native compilation, receipt verification
and unchanged-build reuse. The original My Games launch reached the native
runtime and exposed missing AOT function `0x82163C60`; it is **not playable**.
That error and both catalog entries survived desktop restarts. The failed
entry's managed My Games header was withdrawn without deleting its data.
Castle Crashers launched through original My Games and reached its menu in a
bounded regression session with zero runtime errors/stubs/unimplemented calls.

See [Library validation](../universal-library.md) for final test counts, real
desktop restart captures and the Castle Crashers regression evidence. No clean
Windows, broad gameplay, commercial save/load, Xbox Live, Linux/macOS or ARM64
claim is added. Original Xbox content is not included in the ZIP.

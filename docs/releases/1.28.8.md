# x360-native 1.28.8

The first stable-channel release of x360-native brings the unified desktop launcher, original Xbox 360 dashboard workflows, broader generic AOT support, and new graphics diagnostics. This release ships the desktop application and build/preparation tools, **not** Xbox 360 games or system files.

Stable is the **release channel**, not a claim that every game, dashboard, renderer, or operating system is fully compatible. The project remains under active development.

## New

- **Unified launcher:** a single desktop experience to import authorized content, inspect requirements, prepare native builds, and launch the original dashboard or a prepared game.
- **Original dashboard:** continued work on Retail 17559 (intro, navigation, My Games, local profiles, Guide, launching games and returning); improvements to original storage management, device transfers, saves metadata, recovery, keyboard dialogs, and profile pictures.
- **Generic recompilation:** expanded PowerPC/AOT discovery and runtime handling for more games, with corrections tested while preparing Skate 3 and Need for Speed: Most Wanted (2005). Preparation does not guarantee gameplay compatibility.
- **Graphics:** Xenos D3D12/Vulkan fixes for EDRAM, memory exports, depth bias and synchronization. Native D3D12/Vulkan gains asynchronous pipeline creation, less redundant state and resource handling, and faster constant/descriptor reuse.
- **RENDER-CORE:** optional per-frame capture and deterministic replay, visual/memory verification and A/B benchmarks to diagnose renderer performance without replaying the game manually.
- **Distribution:** six architecture-specific launcher packages, all built and checked on their corresponding Windows, Linux, or macOS GitHub-hosted runner.

## Install or update

Extract the complete package to a new folder and run the desktop launcher (on Windows, `x360-native.exe`). Import content you legally possess; the launcher will identify the originals and indicate what is required to prepare and run them.

**When updating, preserve your existing `data/` folder, profiles, virtual storage, saves and local game inputs.** Back them up first and avoid extracting over an active installation. Repreparing previously compiled titles may be necessary when SDK/runtime versions change.

## Known limitations

- **Windows x64 + Xenos D3D12** has the strongest demonstrated dashboard/gameplay flows. Successful packaging on the five other targets is not evidence that their original dashboard or commercial games have passed full runtime testing. Steam Deck gameplay is not certified.
- Dashboard 17559 is the primary reference. Older dashboard versions (including 1888 and 6717) have incomplete services/resources and are not certified.
- Native D3D12/Vulkan is experimental. Deterministic graphics tools and synthetic tests do not prove a game is visually correct or fast. No new Skate 3 FPS improvement is claimed in this release.
- Individual titles can import or compile but still fail at launch, in menus, during gameplay, on save/reload, or when exiting. No game is certified as fully playable.
- Xbox Live, copyrighted console firmware/system assets, game content and user keys are not included.

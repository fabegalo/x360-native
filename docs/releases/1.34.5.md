# x360-native v1.34.5 — Stable Release

This release includes the changes since v1.28.32, including Native rendering improvements, dashboard lifecycle fixes and restored packaging gates.

## Changed

- Native D3D12 automatically submits recorded work after 512 work units when the hardware queue is idle. `native_eager_submit=0` still disables this behavior; positive thresholds remain supported. Vulkan and Microsoft software adapters keep automatic early submission disabled.
- Native resolution scaling keeps resolve data on the GPU, preserves exact texture addressing and avoids unnecessary resolve waits. Replication dispatches stay within GPU limits through 4x4 scaling on D3D12 and Vulkan.
- Native gains a generic FPS target and the pinned FidelityFX SDK for presenter CAS/FSR. Native/Vulkan selection is available through development access. These options do not certify compatibility or game speed on every title.
- Dashboard-to-game transitions verify runtime artifacts while retaining the complete preparation check at session startup.
- Disc names and icons use the original XEX's SPA metadata. The debug overlay can display FPS and toggle optional performance counters.

## Fixed

- The original dashboard Guide power-off action ends the session.
- Original 17559 avatar profile/MiniCreator flows, default gamer pictures and resource lookup receive compatibility fixes. Pinned original system signatures avoid requiring a separate RSA key file for those verified resources. An absent Kinect is reported as absent.
- FidelityFX preparation resumes after interrupted initialization, fetch or checkout, while rejecting a wrong revision or tracked local changes.
- Package license inventories include the shared catalog library. Linux x64/ARM64 sysroot locks use available Ubuntu packages with verified SHA-256 hashes, retaining the glibc 2.35 baseline.
- Vulkan-only builds link the shared texture-offset option without depending on D3D12 translator sources.
- The package policy permits the single public XEX2 retail loader constant inherited from Xenia/ReXGlue, with preserved BSD notices and explicit maintainer approval. Other key/original-content exclusions remain active.
- Release crash-test fixtures include symbols and check the actual executable's module name.

## Performance evidence and limits

Matched-frame Skate 3 0.0.0.3 replay on Windows x64/RTX 4070 showed lower frame times with the automatic D3D12 threshold, with composed images and GPU-written memory required to match. This is replay evidence for that scene, not a live-gameplay FPS guarantee or a result for other GPUs. Details and negative results are recorded in [performance.md](../performance.md).

Publishing requires verified packages for Windows, Linux and macOS, each x64 and ARM64. Native renderer contracts use D3D12 WARP and Vulkan lavapipe in CI; local hardware evidence is separate. Successful packaging does not establish dashboard boot or gameplay on every platform. Earlier compatibility limitations remain applicable.

## Downloads and updating

Choose the installation archive matching your OS and architecture. Steam Deck uses Linux x64. Only the six verified installation archives are published; their SHA-256 sidecars remain CI artifacts and GitHub displays each uploaded asset's digest.

The application updater preserves imported content, profiles, saves and settings. Runtime/rendering changes can invalidate prepared native outputs; let the application's preparation check determine what must be rebuilt. Originals remain user-supplied and are not distributed with this release.

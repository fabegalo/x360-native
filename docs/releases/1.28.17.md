# x360-native v1.28.17 — Stable Release

This stable release fixes Windows installations in deep folders, where games and saves stored beyond the 260-character Windows path limit stopped working at runtime.

## Fixed

- **Games missing from My Games on Windows:** when the installation folder was deep, installed game files passed 260 characters. The runtime could not read their size, and the original dashboard left the game out of My Games. Skate 3 disappeared this way in the packaged release, while the shorter development folder kept working.
- **Long paths at runtime:** the runtime now keeps its game, user, content, cache and profile folders in the Windows extended-length form (`\\?\`). Saves, installed content, profiles, shader caches and mounted folders work up to about 32,000 characters without changing any Windows setting. The launcher and the runtime still exchange ordinary paths.
- **Gamer picture saving under long paths:** the profile picture and its setting are written with native separators, so they save correctly in extended-length folders.
- **Dashboard file verification:** the original dashboard files are checked correctly in deep installations too.

## Updating

The launcher checks GitHub Releases at startup and offers newer stable versions after asking you. It verifies the downloaded archive before installing it and keeps your data, imported games, saves and profiles. Because the runtime changed, the launcher shows the dashboard and your games as needing preparation again; prepare them so they are rebuilt with the fix.

## Verification and limitations

A new SDK test (patch 0252) builds content with a file beyond 300 characters and checks its attributes and device entry; the related content, storage, profile and title-return tests pass. Passing tests do not prove that every original game behaves correctly in a deep folder; check your library by hand with this release. A crash of the 17559 dashboard right after creating a profile is a known, still-open issue and is not fixed here. Windows x64 is still the only platform with end-to-end evidence. No new game compatibility or GPU performance is claimed.

This independent project contains no copyrighted Xbox 360 games, dashboard files or firmware. Supply only content you are authorized to use.

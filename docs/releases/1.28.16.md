# x360-native v1.28.16 — Stable Release

This stable release includes every fix merged since 1.28.8 and replaces all earlier Releases, which have been removed. v1.28.15 was tagged but never published because its Windows build failed; this release contains its import fix plus the correction for that failure.

## Fixed

- **Game import on Windows:** v1.28.15 failed every Windows import with `symlink_status: The parameter is incorrect: "\\?\C:"`. The link check walked the parent folders of extended-length (`\\?\`) source paths up to the invalid `\\?\C:` root. It now walks the ordinary spelling and inspects each folder through its long form. The containment and link checks are unchanged.
- **Deep game and DLC files (from 1.28.15):** long source paths are enumerated and checked with extended-length paths, so verified files such as `DLC_Rob_Fant_[0x2a2c7864e22311ee].loc` are no longer reported as missing.
- **Extraction of nested content (from 1.28.14):** deep GDFX/STFS output paths and their SHA-256 manifest use extended-length paths. Output errors are reported separately from short reads in the source.
- **Automatic updates (from 1.28.13):** the updater verifies GitHub's SHA-256 asset digest and still accepts the older `.sha256` sidecars.
- **First-use preparation on Windows (from 1.28.11 and 1.28.12):** the shared SDK builds in a short per-user folder, avoiding the SDL3 CMake path overflow, and preparation inputs beyond MAX_PATH are resolved.
- **SDK version:** `rexglue --version` reads the version from the SDK's own repository.

## Updating

The launcher checks GitHub Releases at startup and offers newer stable versions after asking you. It verifies the downloaded archive before installing it and keeps your data, imported games, saves and profiles.

## Verification and limitations

Windows `desktop.catalog` reproduces the v1.28.15 failure without the fix and passes with it, and all six package jobs pass in CI. Passing builds and synthetic tests do not prove that your original game or DLC data imports correctly; check that by hand with this release. Windows x64 is still the only platform with end-to-end evidence. No new game compatibility or GPU performance is claimed.

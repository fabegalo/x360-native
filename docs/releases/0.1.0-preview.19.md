# x360-native v0.1.0-preview.19 — First Technical Preview

**EXPERIMENTAL PRE-RELEASE — Windows x64 — 0.1.0-preview.19**

x360-native runs selected original Xbox 360 software through static PowerPC
recompilation to native code, with a compatibility environment based on ReXGlue.
**Performance-first, correctness-preserving.** This is an early technical preview
for experimentation with exact supported content versions.

## Demonstrated functionality

- Original Dashboard 17559 with text, navigation, and the original boot animation
  with audio.
- The original My Games flow launches Castle Crashers 0.0.1.3 and returns to the
  dashboard through the game's Return to Arcade option, without replaying the intro.
- A Windows graphical application imports content, identifies supported versions,
  reports missing files, manages the library, and guides local preparation.
- Import supports extracted files/folders, GDFX ISO images, and CON/LIVE/PIRS
  packages, including extensionless XBLA packages. Unpack ZIP/RAR/7z first.
- Verified preparation receipts, pinned dependencies, and integrity checks enable
  reuse of valid local preparations.

These demonstrations are recorded project results, not a new gameplay
certification for this package. The release validation focuses on distribution,
integrity, startup, and relevant regression tests.

## Download, extract, and start

1. Download `x360-native-0.1.0-preview.19-windows-x64.zip` and its `.zip.sha256`
   asset from this release. GitHub's automatic source archives are not the app.
2. Optionally compare the ZIP with `Get-FileHash -Algorithm SHA256` in PowerShell
   and the supplied SHA-256 file. Extract the entire ZIP into an empty folder.
3. Open `x360-native.exe`. It opens without Xbox content and creates a local
   `data/` environment. Keep that folder when updating.
4. Import original content you are authorized to use. The app identifies the
   exact version and shows missing requirements; successful extraction alone
   does not establish compatibility.
5. Prepare a supported target. Tools and the pinned SDK are obtained separately
   with your consent. Additional Microsoft C++/Windows SDK components may require
   their official installer and applicable licenses.
6. Start Xbox 360, then use the original My Games menu for a prepared supported
   game. For the demonstrated Castle Crashers version, use Return to Arcade to
   return to Dashboard 17559.

## Included and excluded

The ZIP contains the graphical application, session supervisor, content extractor,
preparation sources/scripts/configuration, dependency lock, integrity manifests,
and project/third-party license notices. The three executables are Release builds.

It does not contain games, dashboards, Xbox fonts, XAM, firmware, proprietary AOT
code, Debug builds, private symbols, user input files, or a prebuilt complete
ReXGlue runtime/toolchain. You must supply authorized original Xbox 360 files.
Recompilation does not grant rights to copy or redistribute those originals or
their derived code. This independent project is not affiliated with Microsoft.

## Known limitations

- Tested platform: **Windows x64**, with D3D12 for the demonstrated runtime.
  Linux and macOS remain roadmap goals. The desktop package targets x86-64-v2 CPUs.
- **Installation on a clean Windows system is NOT VALIDATED.** Startup and local
  environment tests on a development host do not establish the full first-use
  experience with missing Microsoft build tools.
- Compatibility depends on exact title/dashboard versions. No title is certified
  Playable or Fully Functional by this release. Sustained gameplay, save/load,
  full-game entitlement, and broader version compatibility remain unvalidated.
- Profiles, sign-in/out, Guide, settings, achievements, and several console
  services are incomplete. Xbox Live, online multiplayer, and special peripherals
  are not validated.
- Avatars and original system-module integration remain experimental. Motocross
  Madness has known rendering defects and no graphical preparation profile;
  Dashboard 6717 remains a diagnostic target with unresolved failure evidence.
- The project-wide suite previously recorded one pre-existing
  `unit.Depfile escapes characters make treats as syntax` failure. This release
  does not claim that the entire SDK test suite passes.

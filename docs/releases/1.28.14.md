# x360-native v1.28.14 — Extraction Reliability Hotfix

This stable maintenance release includes the Windows extraction fixes merged to main after v1.28.13 and removes the temporary one-time checksum publication bridge.

## Fixed

- **Nested Xbox 360 content extraction on Windows:** extracted GDFX/STFS entries with deep destination paths could fail because opening a Windows output stream was limited by MAX_PATH. The extractor now uses extended-length paths for output directories and files, and for the adjacent SHA-256 manifest.
- **Clearer extraction failures:** output creation/write failures are reported separately from genuine short reads in the source. Failed or incomplete extraction still cannot publish a valid manifest.
- **Release publication cleanup:** the migration-only v1.28.13 sidecar exception is removed. The publishing pipeline continues to verify all six archives and all six SHA-256 sidecars internally, while public Releases include **only the six installation archives**. The permanent updater continues to verify GitHub's published asset digests and supports legacy sidecars.

## Upgrade notes

The launcher checks for stable updates at startup and offers installation only after user confirmation. Existing `data/`, imported content, dashboards, profiles and saves should be preserved during an application update. Do not overwrite an active installation manually; back up local content before changing installations.

The v1.28.13 bridge Release remains available for users upgrading from older launchers that require standalone checksum files. From v1.28.14 onward, normal Releases return to archive-only public assets.

## Testing and limitations

The extractor change includes a synthetic test with output paths over 270 characters. CI build/packaging success and these tests do not substitute for a full manual extraction of the original Fantasy Plaza content on the user's Windows installation. No new game compatibility, GPU performance, or full dashboard support is certified by this hotfix.

The application does not distribute copyrighted Xbox 360 game, system, firmware, keys or dashboard files. Users supply their own content.

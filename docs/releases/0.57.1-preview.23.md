# v0.57.1-preview.23 — Offline Achievements, Launcher Fixes and Original Notifications

Experimental **Windows x64 technical preview**, built from the exact tagged source revision. This is a preview, not a stable or fully compatible Xbox 360 environment. The ZIP contains the x360-native desktop app, supervisor, extractor and verified workspace sources; it does **not** bundle games, dashboard binaries, XEX files, firmware, licensed Xbox assets, profiles or saves.

## Changes since preview.22

- Added offline Xbox 360 achievements using original XUser/XAM/XGI service contracts, with durable, per-XUID/per-Title-ID/per-achievement persistence, XDBF metadata and Gamerscore integration. The original Retail 17559 GamerProfile/Guide and achievement-notification paths are used; no launcher-drawn replacement is claimed.
- Fixed a launcher import-path ancestor traversal loop that could hang folder imports, including the `scripts/..` root spelling used by the development shortcut. Added regression coverage for equivalent paths.
- Reconciled imported games, verified AOT preparations and original My Games registration. The launcher can complete missing verified registrations before launching, while independent supervisor SHA-256 and receipt checks remain mandatory. The maintainer observed Retail 17559 -> My Games -> Forza working through this flow.
- Improved the launcher’s prepared/ready display on reopening, added a persistent fullscreen-session preference and optional crash-stack capture for future diagnosis.
- Improved controller hotplug synchronization and Guide input ownership, including short START taps while BACK+START recognition is enabled.
- Implemented the Retail 17559 original notification compositor’s D1OVL scanout and corrected its BGRA/alpha handling. The maintainer observed the original “10G — Bem-Vindo Ao Horizon” notification before the final color correction; visual acceptance of the corrected colors and transparency is still pending.
- Preserved ReXGlue v0.10.0 at commit `f5337cdc947ff6d4c4196737e2c807a48f2a1fc2`, LLVM 22.1.8 and 114 reproducible SDK patches (through 0115, with 0073 withdrawn).

## Download and installation

Download `x360-native-0.57.1-preview.23-windows-x64.zip` and its matching `.zip.sha256` asset from this Release. Verify SHA-256, extract the entire ZIP into a **new** folder and launch `x360-native.exe`; the automatic GitHub source archives are not standalone Windows applications.

To reuse an earlier installation, preserve its `data/` directory and selected environment containing imported originals, catalog, profiles and saves. Use the app’s supported environment selection/update flow; do not merge ZIP contents or delete existing `.local` directories. Pinned development tools and Microsoft C++ prerequisites may require separate setup with the user’s consent.

Pre-release updates require explicit opt-in to the preview channel; stable installations should not silently receive previews.

## Verification and important limitations

The tag-triggered GitHub Actions workflow builds the Windows x64 desktop distribution from the tagged commit and checks the package, license/content exclusions, provenance, index, ZIP and SHA-256 **before** publishing. Successful packaging does not certify all Xbox 360 runtimes, visual output or gameplay.

- One **real Forza Horizon achievement (ID 155)** was recorded and persisted during a maintainer session. The corrected notification overlay, final color/alpha appearance, in-Guide Gamerscore and persistence across another complete manual gameplay/restart sequence still require acceptance.
- A Retail 17559 **profile-creation crash** (`0xC0000005`, guest read near `0x00000005`) and a separate **Forza session crash** (`0xC0000005`, guest read near `0x02A2C6F8`) remain under investigation; they must not be described as fixed.
- A first-use installation on a clean Windows PC, all import forms, sustained gameplay, commercial saves and full profile/Guide compatibility are **not fully certified**.
- Retail 1888 and other dashboard versions remain separately incomplete and are not certified by Retail 17559 results.
- Xenos/D3D12 is the default Windows renderer. Native/D3D12 is experimental and not certified for playable performance; Vulkan, Linux, macOS and ARM64 are not supported by this ZIP.
- There is no Xbox Live service or full firmware emulation. Importing or recompiling a game does not guarantee that it is playable.

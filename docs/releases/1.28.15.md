# x360-native v1.28.15 — Long-Path Game Import Hotfix

This stable maintenance release fixes an additional Windows long-path issue affecting the import of deeply nested Xbox 360 game files.

## Fixed

- **Verified DLC and game assets:** after extraction, the import phase could fail with `Conjunto incompleto. Falta o arquivo verificado: DLC_Rob_Fant_[0x2a2c7864e22311ee].loc` even when the file existed, because source enumeration and authorized-path checks did not consistently support paths longer than the Windows legacy limit.
- **Import verification:** long source paths are enumerated and checked with compatible extended-length paths. The importer's containment and SHA-256 checks remain mandatory, and unrelated or tampered files are not accepted.
- **Complete catalog inventories:** nested game files are included when identifying imported games, and deep destination files can be inspected without requiring Windows registry changes.
- **Regression coverage:** a synthetic import case includes the affected Fantasy Plaza locator filename in a path exceeding 260 characters.

## Verification and limitations

The code change includes a synthetic long-path test; success of compilation, packaging and synthetic tests does not demonstrate a successful import of the user's original DLC data. The original input still needs manual verification with this release. No additional game compatibility or GPU performance is claimed.

# x360-native v1.28.32 — Stable Release

This stable release follows v1.28.31 and fixes importing disc images that hold files larger than 2 GiB. Everything else is unchanged.

## Fixed

- **Forza Horizon disc 1 could not be imported:** the import stopped with `extract: container extraction limit exceeded; extraction incomplete`. The limits added for System Update packages in v1.28.x refused any single file above 2 GiB in every extraction, and the disc's `media/tracks/colorado/bin.zip` has 2,942,369,996 bytes (2.74 GiB). A file may now use the whole 32-bit size that Xbox 360 disc and package entries allow (just under 4 GiB). The other limits are unchanged: at most 65,536 entries and 8 GiB declared in total. Forza Horizon disc 1 has 2,432 files and 7,320,461,527 bytes. A new test with these sizes fails with the old limit.

## Updating

The launcher checks GitHub Releases at startup and offers newer stable versions after asking you. It verifies the downloaded archive before installing it and keeps your data, imported games, saves and profiles. This release changes only the extractor, not the runtime or the title build files. Whether your titles need preparing again after the update is decided by the full check, as before. If an import stopped with this error, import the disc image again.

## Verification and limitations

The fix was checked with the content tests on Windows x64 (28 test cases, including the new one). The SDK's disc reader, which opens the image before these limits apply, accepts the disc's layout; the same disc was extracted with it on 2026-10-12, before the limit existed. A complete import of Forza Horizon with this release was not run before publication. The open limitations of [v1.28.28](1.28.28.md) still apply. Windows x64 is still the only platform with end-to-end evidence.

The desktop extractor dynamically links x360n-mspack.dll, an unmodified build
of libmspack's LZX decoder, Copyright (C) 2003-2023 Stuart Caie, LGPL-2.1-only.
See libmspack.txt. Exact corresponding source and a standalone CMake build are
included in licenses/sources/libmspack. inventory.json records hashes and the
upstream revision. No Xbox originals, keys or SDK runtime are needed to rebuild
this decoder DLL.

You may modify/replace this library and reverse engineer the combined work
for debugging such modifications, as permitted by LGPL 2.1.

Rebuild on Windows x64, with CMake and a C compiler/Windows build tools:
  cmake -S licenses/sources/libmspack -B decoder-build
  cmake --build decoder-build --config Release

Use your rebuilt x360n-mspack.dll beside x360n-extract.exe in your local build.
For a modified copy of a published package, update the DLL's SHA-256 entry in
package.sha256. This public integrity index has no secret signing key. This
identifies your local modified package, not an official update. Preserve source
notices and identify your library modifications.

Application source/build scripts are also included in app/workspace. For a
complete application rebuild, follow its documented bootstrap, configure with
X360_DESKTOP_ONLY=ON through scripts/devshell.cmd and build x360n-extract in Release.
The ZIP reader uses miniz 1.15 from pinned SDL (Unlicense, miniz.txt). The CMake
recipe enables inflate/archive switches in a private header; safe_zip.cpp maps
SDL allocator names to the standard C allocator. No SDL DLL is linked.
